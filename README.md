# Reader

PDF를 **AI에게 줄 txt 자료**로 바꾸는 개인용 macOS 앱입니다. 스캔한 책은 Apple Vision으로 글자를 읽고(OCR), 글자가 들어 있는 PDF는 그 글자를 그대로 씁니다. 한국어 책과 논문을 주로 염두에 두고 만들었습니다.

## 받기와 처음 실행

1. 저장소의 [Releases](../../releases)에서 가장 최근 `Reader.zip`을 받습니다.
2. 압축을 풀어 `Reader.app`을 원하는 곳에 둡니다.
3. 서명이 없는 앱이라 처음에는 macOS가 실행을 막습니다. 둘 중 하나로 풉니다.
   - 시스템 설정 → 개인정보 보호 및 보안 → "그래도 열기"
   - 터미널에서 `xattr -dr com.apple.quarantine Reader.app`

macOS 14 이상에서 동작하고, 애플 실리콘과 인텔 맥 모두 지원합니다.

## 쓰는 법

1. PDF 파일이나 폴더를 창에 끌어다 놓습니다. 폴더는 하위 폴더까지 훑습니다.
2. "변환 시작"을 누릅니다.
3. 원본 PDF 옆에 같은 이름의 `.txt`가 생깁니다.

이미 같은 이름의 txt가 있으면 건너뜁니다. 다시 만들려면 "기존 txt 덮어쓰기"를 켭니다.

| 옵션 | 기본 | 설명 |
|---|---|---|
| 쪽 마커 [p.N] | 켜짐 | 원본 쪽 번호를 넣습니다 |
| 소제목·인용 표시 | 켜짐 | 소제목에 `## `, 인용문에 `> `를 붙입니다 |
| 안내 머리말 | 켜짐 | 맨 위에 제목과 표시의 뜻을 한 줄로 적습니다 |
| 각주 번호 지우기 | 켜짐 | 문장 끝에 붙은 각주 번호와 깨진 말줄임표를 정리합니다 |
| 항상 OCR | 꺼짐 | PDF에 글자가 들어 있어도 무시하고 Vision으로 다시 읽습니다 |
| 기존 txt 덮어쓰기 | 꺼짐 | 이미 있는 txt를 다시 만듭니다 |

변환이 끝나면 파일마다 쪽수, OCR로 읽은 쪽 수, 인식이 불확실한 쪽이 표시됩니다.

## 결과물의 모양

```
# 책 제목

(이 글은 PDF에서 자동으로 옮긴 것입니다. 전체 274쪽. [p.N]은 원본의 쪽 번호, ##는 소제목, >는 인용문 표시입니다. …)

[p.12]

## 소제목

본문 문단은 줄바꿈 없이 한 줄로 이어집니다.

> 인용문
```

- 쪽 위아래에 반복되는 장 제목과 쪽번호는 지웁니다.
- 2단 편집은 왼쪽 단을 다 읽은 뒤 오른쪽 단을 읽습니다.
- 쪽을 넘어가는 문단은 끊지 않고 잇습니다. 쪽 마커는 그 쪽에서 새로 시작하는 첫 문단 앞에 옵니다.

## 알아 둘 한계

- **글자 인식 오류**는 그대로 남습니다. 스캔 상태가 나쁘거나 글자가 작으면 많아집니다.
- **띄어쓰기**: 한국어 책은 낱말 중간에서도 줄이 바뀌어서, 줄을 이을 때 붙일지 띄울지를 어림합니다. 가끔 틀립니다.
- **소제목과 인용문**은 모양(위치, 줄 길이, 빈 줄)으로 판별합니다. 책에 따라 빠지거나 잘못 붙을 수 있습니다.
- **표지·차례·판권 쪽**은 글자가 흩어져 있어 순서가 어지럽게 나옵니다.
- **글자가 깨져 나올 때**: PDF에 들어 있는 글자 자체가 틀린 경우입니다. "항상 OCR"을 켜고 다시 변환해 보세요.
- 다루지 않는 것: 표의 구조, 각주를 본문과 분리하기, 세로쓰기, 3단 이상, 큰 책을 여러 파일로 나누기.

## 명령줄 도구

같은 기능을 터미널에서 쓸 수 있습니다. Releases에 `reader-cli`가 함께 들어 있습니다.

```bash
./reader-cli 책.pdf                 # 책.txt 생성
./reader-cli --overwrite 폴더/       # 폴더 안의 PDF 전부, 기존 txt 덮어쓰기
./reader-cli --stdout 책.pdf        # 파일로 저장하지 않고 화면에 출력
./reader-cli --help                 # 옵션 목록
```

## 직접 빌드하기

Xcode 또는 Command Line Tools가 필요합니다.

```bash
swift test              # 테스트
scripts/make-app.sh     # build/Reader.app, build/reader-cli 생성
```

설계와 판별 규칙은 [SPEC.md](SPEC.md)에 있습니다.
